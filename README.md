# Google Cybersecurity Certificate: Projetos Práticos

Projetos práticos do Google Cybersecurity Professional Certificate, com foco em **SOC Analyst I / Blue Team**.

## Projetos

| Módulo | Projeto | Habilidades |
|---|---|---|
| Linux | [Permissões de arquivos](linux/permissoes-de-arquivos/) | `ls -la`, `chmod`, princípio do menor privilégio |
| SQL | [Filtros em consultas](sql/filtros-em-consultas/) | `WHERE`, `AND`, `OR`, `NOT`, `LIKE`, investigação de logins |
| Gestão de ativos | [Inventário de ativos](gestao-de-ativos/inventario-de-ativos/) | Inventário, classificação de dados, tríade CIA |
| Gestão de ativos | [Registro de riscos](gestao-de-ativos/registro-de-riscos/) | Avaliação de riscos, probabilidade x impacto, NIST CSF |
| Gestão de ativos | [Vazamento de dados](gestao-de-ativos/vazamento-de-dados/) | Menor privilégio, NIST SP 800-53 (AC-6), análise de incidente |
| Gestão de ativos | [Controle de acesso](gestao-de-ativos/controle-de-acesso/) | Análise de logs, autenticação e autorização, AAA, offboarding |
